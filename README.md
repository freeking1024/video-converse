# FrameFlow｜本地视频画幅转换工具

FrameFlow 是一个完全在浏览器本地运行的视频画幅转换与轻量剪辑工具。它可以把横屏视频转换为适合小红书、抖音、视频号、YouTube Shorts 和 Instagram Reels 的竖屏或方形视频。

视频文件不会上传到服务器，预览、编辑和导出均在当前设备完成。

## 直接下载使用

### 单文件版（推荐）

点击下面的链接下载 `frameflow.html`，下载后直接双击，用 Chrome 或 Edge 打开即可使用，无需安装依赖，也不需要启动服务器。

**[⬇️ 下载 FrameFlow 单文件版](https://github.com/freeking1024/video-converse/raw/refs/heads/main/frameflow.html)**

如果浏览器直接打开了文件内容，请右键链接选择“链接另存为”，并确认文件名以 `.html` 结尾。

> 建议使用最新版 Chrome 或 Edge。Safari 的视频编码支持因系统版本而异，若无法导出 MP4，请改用 Chrome 或 Edge。

## 主要功能

- 支持 `9:16`、`16:9`、`1:1`、`4:5`、`3:4`、`21:9` 六种常用画幅
- 焦点裁切、模糊背景填充、完整留边三种不拉伸适配方式
- 拖拽画面调整人物或主体的焦点位置
- 支持 720p、1080p、4K 与 24/30/60 fps 输出
- 根据浏览器能力自动选择 MP4 或 WebM 编码
- 可保留原视频声音
- 支持设置入点、出点、分割和删除片段
- 支持旋转、水平/垂直翻转和 0.5×–2× 变速
- 提供小红书、抖音、视频号、Shorts、Reels 安全区预览
- 支持浏览器自动听写、SRT 导入、字幕校正与字幕样式设置
- 支持多视频任务队列和逐个批量导出

## 使用方法

1. 下载并打开 `frameflow.html`。
2. 点击“导入视频”，或者把视频拖入页面。
3. 选择目标画幅和适配方式。
4. 根据需要调整焦点、片段、字幕及输出参数。
5. 点击“导出视频”，保持页面打开直至下载开始。

浏览器采用实时录制方式生成视频，因此导出耗时通常接近成片时长。较高的分辨率和帧率会占用更多内存；如果 4K 或 60 fps 导出失败，请改用 1080p / 30 fps。

## 隐私说明

- 视频画面、剪辑操作和视频导出均在本机完成，不会上传到本项目的服务器。
- “自动听写”依赖浏览器提供的 `SpeechRecognition` 能力，需要麦克风权限，并可能由浏览器提供商的语音服务处理音频。
- 如需完全本地的字幕工作流，请关闭自动听写，使用本地 SRT 文件并手动校正。

## 本地运行源码版

你也可以克隆仓库后直接打开 `index.html`。为了获得更稳定的浏览器兼容性，建议启动一个本地静态服务器：

```bash
git clone https://github.com/freeking1024/video-converse.git
cd video-converse
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173
```

## 重新生成单文件版

修改 `index.html`、`styles.css` 或 `app.js` 后，运行：

```bash
node scripts/build-standalone.mjs
```

该命令会重新生成可独立运行的 `frameflow.html`。提交代码前请一并提交更新后的单文件版本。

## 技术说明

FrameFlow 不依赖前端框架，核心使用浏览器原生能力：

- Canvas API：画幅裁切、背景填充、旋转、翻转和字幕合成
- MediaRecorder API：在本地录制并导出处理后的视频
- Web Audio API：在导出视频中保留音频
- SpeechRecognition API：可选的浏览器自动听写

## 已知限制

- 导出格式取决于浏览器和操作系统实际支持的编码器。
- 移动浏览器可能因内存限制无法稳定处理长视频或 4K 视频。
- 自动听写能力并非所有浏览器都支持，识别结果也需要人工校对。
- 导出期间请勿关闭页面、让设备休眠或频繁切换后台。
